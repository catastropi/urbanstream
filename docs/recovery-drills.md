# 장애 훈련·실제 장애 기록 (STEP 3B)

이 표는 두 종류를 같이 적는다.

- **훈련**: `scripts/drill.py run <훈련>` 으로 일부러 일으킨 것. 끝나면 도구가 표 끝에 한 줄을 붙인다(원시 기록은 `data/drills/drills.jsonl`).
- **자연**: 일부러 일으키지 않았는데 실제로 생긴 장애. `python scripts/drill.py record …` 로 적거나 손으로 적는다. 근거는 메모의 DEFERRED 항목.

시나리오 번호(R1~R14)는 `docs/adr/0017-step3b-recovery.md` 표, 증상별 명령은 `docs/runbooks/recovery.md`.
STEP 2 측정 보고서는 '훈련' 행의 구간을 수집 공백에서 따로 센다. 수집을 끊는 훈련은 STEP 2 무거운 측정이 끝난 뒤에만 한다.

칸 설명: 알림 도착 = 처음 받은 알림 시각(없으면 '없음'). 복구까지 = 되돌리거나 고친 뒤 모두 정상이 될 때까지. 수집 공백 = 분.
잃은 메시지 = 다시 만들 수 없는 메시지 수(모르면 '-'). 시각을 모르는 칸은 비우지 않고 '모름' 이라 적는다.

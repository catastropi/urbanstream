# geo (예약된 자리 — 코드 없음)

처음 설계에서는 공간 유틸리티(좌표 변환, 링크↔격자 매핑, 돌발↔영향 링크 탐색)를 여기에 둘 계획이었으나,
실제 구현은 다른 곳에 들어갔다. 이 폴더에는 코드가 없다.

| 계획했던 기능 | 실제 위치 |
|---|---|
| TM(EPSG:5181) → WGS84 | `streaming/geo_tm.py` (표준 라이브러리 구현, pyproj 대조 오차 약 1e-13도) |
| 돌발 ↔ 영향 링크 (연결 = link_id → 300 m → no_link) | `batch/marts.py` (PostGIS SQL) |
| 링크 ↔ 기상 격자 | 수집 격자 1개(60,127)로 고정 — 별도 매핑 코드 없음 |

옮기기 전까지 이 README 가 안내 역할만 한다. (ADR-0007, ADR-0009 §6)
